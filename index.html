Pay theaug with crypto

Pick the network your wallet is on. Send only that coin to its address.

  • Send only on Ethereum (ERC-20). BNB Smart Chain uses the same address, so check the network in your wallet.

  • Send only on BNB Smart Chain (BEP-20). Ethereum uses the same address, so check the network in your wallet.

  • Send only on the TRON (TRC-20) network.

  • Send only Litecoin (LTC) on the Litecoin network.

Before you confirm, compare the highlighted characters with what your wallet shows.
